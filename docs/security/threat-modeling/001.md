ADR 001: Modelado de amenazas para endpoint de get /api/v1/products/{id}

Contexto
Para el siguiente modelado de amenazas se utilizara el modelo STRIDE

Decisión
Se determino que para este ejemplo abarcan las siguientes amenazas:
STID
S = Hacerse pasar por otro usuario o sistema.
T = Modificar datos, mensajes o código sin autorización.
I = Exponer información confidencial
D = Saturar un servidor con solicitudes.
